# 05. 은행 일반 주담대 — 기존 문서가 다루지 않은 것

기본 숫자(지역 cap 6/4/2억, LTV 70/60/40/0%, 스트레스 DSR, 신용·주담대 1,000만)는 [bank-mortgage.md](bank-mortgage.md)가 갖는다. 여기서 다시 적지 않는다.
이 문서는 그 밖의 **질문 상태 · 정부 탭과 답 공유 · 부채 7종 · 예비배우자 · 서민 60% 경계 · 카드 문구**를 본다.

규칙: `bank.md`, `_common.md`. 코드: `src/eligibility/bank.jsx`, `person.bankSteps` · `homeBucketOf` · `withSpouse`, `engine_bank_dsr.js`, `engine.regulatoryLtv` · `realDemandHeadGap`.

매물은 따로 적지 않으면 중계동 **중앙하이츠 84.21㎡(7억 200만)**, 소득 4,000만이다.

## B. 정부 탭과 답 공유

두 탭은 같은 `elig`를 쓴다. 한쪽 답은 다른 쪽에서 다시 묻지 않는다(`ux.md` 3단계).

| ID | 우선 | 종류 | 조작 | 기대 |
|---|---|---|---|---|
| BK-12 | P1 | 화면 | 은행: `없어요` · 생애최초 `네` · `본인 소득만` → 위 탭 `정부대출` | 가족정보 `배우자 없음`이 선택돼 있다. 생년월일만 넣으면 `지금 가진 집이 없나요?`는 `네`, 생애최초는 `네`가 이미 선택. 결혼 질문부터 답한다 |
| BK-13 | P1 | 화면 | 은행: `처분할 거예요` → 정부 탭 | 무주택 질문이 `아니오`로 선택되고 닫힘 카드. 정부 상품 없음 |
| BK-14 | P1 | 화면 | 정부: 무주택 `아니오` → 은행 탭 | 주택 버킷이 **아무것도 선택 안 됨**(1주택인데 처분 여부 모름). 다시 고르게 한다 |
| BK-15 | P1 | 화면 | 정부: 배우자 없음 · `배우자가 없어요`까지 답함 → 은행: `배우자 소득 합산` | 정부 결혼 답이 비워진다. 정부 탭으로 가면 결과가 사라지고 결혼 질문이 다시 열린다. `배우자가 없어요`는 잠긴다. 목록은 은행 답으로 정밀 유지 |
| BK-16 | P1 | 화면 | 정부: 기혼 · 밴드 `3~5천` → 은행 탭 | 은행 질문을 다시 묻지 않고 카드. 요약 `본인 4,000만원 + 배우자 4,000만원` |
| BK-17 | P2 | 화면 | 정부 정밀값 3,500 입력 → 은행 탭에서 밴드를 다시 누름 | 정밀값이 지워지고 밴드 대표값으로 계산. 정부 탭으로 돌아가도 정밀값은 비어 있다 |
