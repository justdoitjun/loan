# 10. 레이아웃 — 반응형 · 한 줄 맞춤 · 오버레이

규칙: `CLAUDE.md` 「화면 디자인 규칙 (최우선)」, `ux.md` 「반응형 · 글자 크기」.
코드: `src/fitLines.js`(`MIN_PX = 10`), `src/ui.jsx`(`AppShell` 최대 460px, `useOverlayLock`, `BottomSheet`).

업무 숫자가 맞아도 한 줄이 잘리거나 넘치면 사용자는 숫자를 잘못 읽는다. 그래서 이 문서도 업무 테스트에 넣는다.

## 준비

브라우저 개발자 도구의 기기 모드로 폭을 바꾼다: **320 · 360 · 390 · 460 · 768 · 1440px**. 높이는 667(iPhone SE)과 844를 같이 본다.
긴 이름 매물: 은평구 진관동 `박석고개1단지힐스테이트(101~111동)BL2-12` 59.85㎡ / `상림마을7단지아이파크(730~742동)BL1-14` 84.63㎡.

## 케이스

| ID | 우선 | 종류 | 폭 · 화면 | 기대 |
|---|---|---|---|---|
| LY-01 | P1 | 화면 | 모든 폭, 모든 화면 | 가로 스크롤이 없다. 본문 열은 최대 460px, 그보다 좁으면 화면 폭(좌우 여백 12~18px) |
| LY-02 | P1 | 화면 | 320, 진관동 목록 | 긴 단지 이름이 **줄을 내리지 않고** 글자가 작아진다. 10px까지 줄여도 안 되면 말줄임(…)으로 칸 안에 둔다 |
| LY-03 | P1 | 화면 | 320, 목록 오른쪽 `대출 N억 N만 ›` | 한 줄. 왼쪽 이름과 겹치지 않는다. 숫자가 잘려서 다른 숫자로 읽히면 실패 |
| LY-04 | P1 | 화면 | 첫 화면 제목 | 글에 넣은 `<br>` 자리에서만 줄이 바뀐다(`내 소득으로` / `가능한 집은 얼마일까요?`) |
| LY-05 | P2 | 화면 | 320, 경로 `서울특별시 > 동대문구 > 청량리동` | 한 줄. 넘치면 글자가 작아지고, 구·동 버튼을 누를 수 있다 |
| LY-06 | P1 | 화면 | 320, `소득 1억 2,000만원으로 평가해볼까요?` | 한 줄(`data-fit="line"`) |

| LY-10 | P2 | 화면 | 320, 은행 카드 `최소 대출 약 N.N억` + 상품명 | 한 줄씩. 상세이유 줄 이름(`담보(LTV 70% · 방공제 상쇄)`)과 금액이 한 줄 |
| LY-11 | P2 | 화면 | 320, 결혼 4버킷 · 주택 4버킷 설명 | 버튼 밖으로 넘치지 않는다 |
