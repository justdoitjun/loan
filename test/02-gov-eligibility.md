# 02. 정부 탭 — 질문 흐름 · 건너뛰기 · 결과 카드

규칙: `ux.md` 3단계, `gov_common.md` 「정부탭 시나리오 로직」, `architecture.md` 「판정 엔진 구조」.
코드: `src/eligibility/gov.jsx`, `person.eligSteps` · `withSpouse` · `bucketOf`, `engine.deriveFacts` · `judgeAll` · `nearIncomeCap`.

숫자(한도·상한)는 [03-didimdol.md](03-didimdol.md)가 본다. 이 문서는 **질문이 언제 열리고 닫히는지, 답이 어떻게 정리되는지, 결과를 어떻게 보여 주는지**를 본다.

## 준비

새로고침 → 소득 슬라이더 → 중계동 매물 하나 → Yes → `정부대출`.
따로 적지 않으면 소득 4,000만, 매물 `동진 38.79㎡`(2억 2,950만).

생년월일은 휠이다. 처음엔 2026이 가운데에 있고 비어 있다. **년을 누르면 그해 1월 1일**이 들어간다. 월·일은 그다음에 누른다.
나이는 오늘(2026-10-12) 기준 만 나이다. 1990-01-01 = 만 36세, 1997-12-31 = 만 28세, 1987-01-01 = 만 39세, 1986-10-01 = 만 40세.

> **날짜 의존**: 다른 날 돌리면 위 나이가 같게 나오도록 생년월일을 옮긴다. 경계 케이스(GV-31·32)는 오늘과 같은 월·일로 맞춘다.

## A. 질문 순서 (`eligSteps`)

순서: ① 가족정보 카드 → ② 무주택 → ③ 생애최초 → ④ 결혼 → ⑤ 배우자 소득(합산 대상이 있을 때만) → ⑥ 청년 주택드림(만 39세 이하만) → 결과.

| ID | 우선 | 종류 | 상태 / 조작 | 기대 |
|---|---|---|---|---|
| GV-01 | P2 | 화면 | 처음 진입 | 가족정보 카드만 보인다. `지금 가진 집이 없나요?`와 `가능한 대출` 칸은 없다 |
| GV-02 | P1 | 화면 | 본인 생년월일만 넣음 | 아직 무주택 질문이 없다. 배우자 `있음/없음`을 골라야 열린다 |
| GV-03 | P1 | 화면 | 본인 1990 · `배우자 없음` | `이렇게 보고 계산해요 / 만 36세 · 배우자 없음 · 자녀 0명(미성년 0명)`, 무주택 질문, `가능한 대출 / 위를 채우면 계산해요` |
| GV-04 | P1 | 화면 | `+ 자녀 추가`만 누르고 생일을 비워 둠 | 무주택 질문이 **닫힌다**(가족정보 미완). 자녀를 넣거나 `삭제`하면 다시 열린다 |
| GV-05 | P1 | 화면 | 자녀 생일을 2026 → 11월 → 1일(미래) | 미래 날짜라 입력 완료로 보지 않는다. 무주택 질문이 닫힌 채다 |
| GV-06 | P2 | 화면 | `배우자 있음` | 배우자 생년월일 휠(`몰라도 넘어갈 수 있어요`)이 열린다. 비워도 다음 질문이 열린다 |
| GV-07 | P1 | 화면 | 무주택 `아니오` | 닫힘 카드와 무주택 예외 안내(오피스텔, 25평 미만 단독주택 등). 생애최초 이하 질문·결과가 **없다** |
| GV-08 | P1 | 화면 | 무주택 `네` | `생애 처음으로 집을 사시는 건가요?` |
| GV-09 | P1 | 화면 | 생애최초 답 | `결혼하셨나요?` 4버킷 |
| GV-10 | P1 | 화면 | `배우자가 없어요` | 소득 칸 대신 `배우자가 없어서 소득은 본인 4,000만원으로만 봐요.` 만 39세 이하면 청년 주택드림 질문이 이어서 열린다 |
| GV-11 | P1 | 화면 | 만 36세 · 배우자 없음 · 청년 질문 `아니오·해당없음` | 질문 더미가 접히고 `입력한 조건` 요약 + 결과가 뜬다 |
| GV-12 | P1 | 화면 | 만 40세(1986-10-01) · 배우자 없음 | 청년 주택드림 질문이 **나오지 않고** 바로 결과. 요약에 `청년 주택드림` 줄이 없다 |
| GV-13 | P1 | 화면 | 만 39세(1987-01-01) | 청년 질문이 나온다. 답해야 결과가 뜬다 |

## B. 결혼 버킷과 배우자 토글 (`MaritalChoice` · `withSpouse`)

| ID | 우선 | 종류 | 상태 / 조작 | 기대 |
|---|---|---|---|---|
| GV-20 | P1 | 화면 | 가족정보 `배우자 없음` | `혼인신고한 지 7년 안 됐어요`·`7년 넘었어요`는 흐리고 눌리지 않는다. 설명은 `위 가족정보에서 '배우자 있음'을 고르면 열려요` |
| GV-21 | P1 | 화면 | 가족정보 `배우자 있음` | `배우자가 없어요`가 잠긴다(`위 가족정보에 배우자가 있어요`). `곧 할 거예요`는 열려 있다 |
| GV-22 | P1 | 화면 | `배우자 없음` + `곧 할 거예요` | 소득 칸 제목 `예비배우자 세전 연소득은 어느 구간인가요?`. 가족 요약 `예비배우자 있음(결혼예정)` |
| GV-23 | P1 | 화면 | `배우자 있음` + `7년 안 됐어요` + 밴드 `3~5천` → 가족정보에서 `배우자 없음`으로 바꿈 | 결혼 답과 밴드가 **조용히 비워진다**. 결혼 질문이 다시 열린다. 결과가 사라진다 |
| GV-24 | P1 | 화면 | `배우자 없음` + `곧 할 거예요` + 밴드 `3~5천` → `배우자 있음` → 다시 `배우자 없음` | 결혼예정은 유지되고 밴드도 **남는다**(예비배우자 소득은 계속 합산) |
| GV-25 | P2 | 화면 | `배우자가 없어요` 상태에서 가족정보 `배우자 있음` | 결혼 답이 비워지고 `배우자가 없어요`는 잠긴다 |
| GV-26 | P2 | 로직 | `withSpouse({marital:"married", marriedWithin7:true, spouseBand:"3to5"}, false)` | `marital=null`, `marriedWithin7=null`, `spouseBand=null`, `spouseIncomeRaw=""` |

## C. 배우자 소득 밴드와 정밀 입력 (`nearIncomeCap`)

밴드 대표값: `~3천` 1,500 · `3~5천` 4,000 · `5~7천` 6,000 · `7천~` 8,000(만원).
부부합산이 **어느 상품 소득상한의 ±1,000만** 안이면 `소득상한 경계 / 정확한 금액을 넣으면 더 좁혀요` 입력칸이 열린다.

| ID | 우선 | 종류 | 상태 / 조작 | 기대 |
|---|---|---|---|---|
| GV-40 | P2 | 화면 | 밴드를 고름 | `3천만원 ~ 5천만원 선택 · 계산은 구간 대표값 약 4,000만원으로 봐요…` |
| GV-41 | P1 | 화면 | 본인 5,000 + `3~5천` = 9,000 | 경계 입력칸이 열린다(신혼 8,500과 500 차이) |
| GV-42 | P1 | 화면 | 본인 2,000 + `~3천` = 3,500 | 입력칸이 **없다**(가장 가까운 상한 6,000과 2,500 차이) |
| GV-43 | P1 | 화면 | GV-41에서 정밀값 `3500` | 합산이 8,500으로 바뀌고 결과가 다시 계산된다. 요약 소득 줄 `본인 5,000만원 + 배우자 3,500만원` |
| GV-44 | P1 | 화면 | 정밀값을 넣은 뒤 밴드를 `5~7천`으로 바꿈 | 정밀값이 **지워지고** 대표값 6,000으로 계산 |
| GV-45 | P2 | 화면 | 정밀값을 넣어 경계에서 벗어남(예: `100`) | 입력칸이 닫히지 않는다(이미 넣은 값 유실 방지) |
| GV-46 | P2 | 화면 | 정밀값 `0` | 배우자 소득 0으로 계산. 맞벌이 플래그가 꺼진다(신생아는 외벌이 1.3억 상한으로 간다) |
| GV-47 | P3 | 화면 | 정밀값에 `-500` 입력 | 0으로 본다(`num`). 음수 합산이 되면 실패 |

## D. 세대주 추정 안내 (노랑)

세대주는 묻지 않는다. 기혼이거나, 배우자 없는 만 30세 이상이거나, 만 30세 미만 미혼인데 미성년 자녀가 있으면 세대주로 본다.

| ID | 우선 | 종류 | 상태 | 기대 |
|---|---|---|---|---|
| GV-50 | P1 | 화면 | 만 36세 · 배우자 없음 · 자녀 없음 · 미혼 | 결과 위 `단독세대는 상담역이 확인해요` (`만 30세 이상 단독세대로 보고 계산했어요…`) |
| GV-51 | P1 | 화면 | 만 28세(1997-12-31) · 배우자 없음 · 자녀 없음 | `세대주 요건이 아직 안 잡혀요` / `만 28세, 부양가족 없음. 미성년 형제·직계존속을 6개월 이상 부양하면 열릴 수 있어요.` 일반가구는 `안 열린 대출`에 세대주 조건으로 |
| GV-52 | P1 | 화면 | 만 28세 · 미혼 · 자녀 2020-01-01 | 노랑 안내가 **없다**(미성년 자녀 부양 → 세대주). 단독세대 안내도 없다 |
| GV-53 | P2 | 화면 | 만 36세 · 미혼 · 자녀 1명 | 단독세대 안내가 **없다**(부양가족 있음 → 일반 티어). → DG 표 참조 |
| GV-54 | P2 | 화면 | 만 28세 · 결혼예정 | 세대주 안내가 뜬다(결혼예정은 기혼이 아니다). 그래도 `생애최초 신혼가구`는 열릴 수 있다 → Q-02 |

## E. 접기 · 고치기

| ID | 우선 | 종류 | 상태 / 조작 | 기대 |
|---|---|---|---|---|
| GV-60 | P2 | 화면 | 답을 다 채움 | 제목 `지금은 어떤 상태인가요?`와 질문 더미가 사라지고 `입력한 조건 / 고치기 ▾` 카드. 요약 줄: `가족` · `무주택 네` · `생애최초` · `결혼` · `소득` (+만 39세 이하면 `청년 주택드림`) |
| GV-61 | P2 | 화면 | `고치기` | 질문이 다시 펼쳐지고 요약은 숨는다. 버튼은 `접기` |
| GV-62 | P1 | 화면 | 펼쳐서 생애최초를 바꿈 | 답이 다 찬 상태면 펼친 채로 결과가 바로 다시 계산된다 |
| GV-63 | P1 | 화면 | 펼쳐서 `배우자 있음`으로 바꿔 결혼 답이 비워짐 | 결과가 사라지고(미완) 펼침 상태가 풀린다. 다시 다 채우면 **자동으로 접힌다**(두 번째도 접혀야 한다) |
| GV-64 | P3 | 화면 | 결혼예정 · 배우자 없음 | 요약 `가족` 줄이 `예비배우자 있음`, `소득` 줄이 `본인 … + 예비배우자 …` |

## F. 결과 카드

| ID | 우선 | 종류 | 상태 | 기대 |
|---|---|---|---|---|
| GV-70 | P1 | 화면 | 통과 2개 이상 | `가능한 대출 N가지`. 대략 한도 큰 순. 첫 카드만 `한도 최대` 표시와 진한 테두리 |

| GV-75 | P2 | 화면 | 정부 탭 결과 | 은행 `일반 주택담보대출` 카드가 섞이면 실패(`GOV_RULES`만 판정) |

| GV-77 | P1 | 화면 | 카드 → `이걸로 볼게요 →` | 방법 화면. 위 제목(eyebrow)이 고른 카드 제목과 같다 |
| GV-78 | P2 | 화면 | 정부 탭에서 `매물목록으로` | 목록으로 간다. 자격 답은 남는다 → 07 문서 |
