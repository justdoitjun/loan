# 04. 보금자리론 — 스텁 동작 고정

규칙: `bogeumjari.md`는 **아직 비어 있다.** 코드 숫자는 전부 ⚠️ 가정치다.
그래서 이 문서는 "맞는가"가 아니라 **지금 코드가 어떻게 동작하는가를 고정**하는 회귀용이다. 규칙을 채우면 이 문서의 기대값을 규칙 문서에서 다시 뽑는다.

코드: `src/products/bogeumjari.js`(자격·상한), `data.PRODUCTS.bogeumjari`(LTV 70% · DSR 60% · 3.8% · 방공제 상쇄 · cap 3.6억), `products/limit.js` `DEBT_VIEW.bogeumjari = "interestOnly"`.

## 현재 규칙 (코드)

| 항목 | 값 |
|---|---|
| 진입 | 무주택 하나 (세대주·나이·가족 안 봄) → Q-03 |
| 소득상한 | 신생아 1.3억 → 신혼 1억 → 미성년 2자녀 9,000 → 기본 7,000 (위에서 첫 매치) |
| 가격 | 6억 |
| 면적 | 없음 |
| 한도 | (신혼 또는 미성년 2자녀 또는 신생아) 4억 / 기본 3.6억 |
| LTV | 70%. 규제지역 은행 표를 타지 않는다 |
| 상환능력 | DSR 60%, 3.8%, 30년. 기존 부채는 **이자만** 5.5%(`RULE.creditRate`). 스트레스 금리 없음 |
| 방공제 | 카드는 상쇄(빼지 않음). 방법 화면 기본은 차감 |
| 지역 cap | 없음 |
