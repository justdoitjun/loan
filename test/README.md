# 테스트 케이스 문서

이 폴더는 그린라이트의 **업무 규칙**이 화면과 계산에서 지켜지는지 확인하는 케이스 모음이다.
사람이 브라우저로 눌러 보는 화면 케이스와, 계산 함수만 돌려 보는 로직 케이스가 같이 있다.

기준일은 **2026-10-12**이고, 기준 코드는 `main` 6416a40이다. 매물 시세는 `src/data/seoul/units_20261011.json`(스냅샷 202610, `median_6m_max10`)이다.
나이·신생아·결혼 기간 케이스는 날짜에 따라 결과가 바뀐다. 다른 날 돌리면 각 문서의 「날짜 의존」 메모대로 생년월일을 옮긴다.

## 케이스 읽는 법

- ID 앞자리가 문서다. `FS` 첫 화면, `GV` 정부 탭 흐름, `DG` 디딤돌, `BJ` 보금자리, `BK` 은행 추가, `ST` 방법 화면, `X` 상태·이동, `IC` 소득 자가진단, `DA` 데이터, `LY` 레이아웃.
- 우선순위: **P1** 숫자나 자격이 틀리면 사용자가 잘못 판단한다 / **P2** 흐름·안내가 틀린다 / **P3** 표시·문구.
- 종류: **화면** = 브라우저에서 누른다 / **로직** = 함수만 돌린다(`node`로 `src/*.js` import). 둘 다 쓴 케이스는 로직으로 먼저 거르고 화면으로 확인한다.
- `→ F-xx`가 붙은 케이스는 **지금 코드로는 실패하는 게 정상**이다. 기대 칸은 규칙 기준이고, "현재" 칸에 지금 코드가 내는 값을 적었다.
- `⚠️ 가정치` 표시는 규칙 문서가 아직 가정한 숫자다. 그 케이스는 **지금 코드의 동작을 고정**하는 회귀용이다. 숫자를 정하면 문서부터 고친다.

## 금액 단위와 반올림

- 계산은 만원 단위. 화면 `억`은 만원 ÷ 10,000이다.
- `eok()`은 소수 첫째 자리로 반올림한다. `2억 41만` → `약 2.0억`. 머리 숫자만 보고 통과시키지 않는다. 만 원 단위 숫자(상세이유·카드 자본금)로 판정한다.
- `won()`은 만 원 미만을 반올림한다. 0은 `0만`으로 보인다.
