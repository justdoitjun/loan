# 은행 일반 주택담보대출 판단기준

> **아직 안 채웠다. 코드도 없다** — 화면의 은행탭은 placeholder("곧 준비")다.
> 채울 때 목차는 `didimdol.md`와 동일하게. 공통 부분은 `_common.md`.

붙일 때 정할 것:
- DSR 40%(차주단위), 산정만기, 스트레스 DSR 적용 여부.
- MCI/MCG로 **방공제 상쇄 가능** → `offsetsRoomDeduction: true`.
- 실행이 빠르다(정부상품 ~2개월 대비) — 잔금일 축에서 정부상품과 갈리는 지점.
- `products/bank.js` 규칙 데이터 + `DEBT_VIEW.bank = "principalAndInterest"` + 탭 연결.
- **DSR이 '부채 잔액 하나'만으로 충분한지 확인할 것.** 부족하면 그때 **은행 경로에서만** 입력을 늘린다 —
  디딤돌 화면에 안 쓰는 질문을 되살리지 말 것.

여기가 **부채 레버가 실제로 살아나는 유일한 경로**다(디딤돌은 cap·LTV가 먼저 걸려 레버가 잘 안 먹는다).
