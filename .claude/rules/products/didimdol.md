## 0. 판정 순서

```
① 5종별 자격 (requires)
② 상한 검사 — 소득 · 가격 · 면적
③ 한도 = Min( LTV기반, DTI기반, 종별 대출한도 )
```
5종은 배타적이지 않다. **자격 되는 건 전부 목록에 올린다.** 하나로 좁혀 추천하지 않는다.
탈락해도 "무엇이 얼마 초과인지"를 항상 같이 돌려준다.

**공통 진입 게이트는 무주택** — 세대주 포함 세대원 전원 무주택
(생애최초 주택구입자는 생애 전 기간 무주택).

### MVP에서 구현하지 않는 것 (결정됨)
원문에 있으나 다루지 않는다. 상담역 확인 영역.

- **자산 심사** (2025년 기준 5억 1,100만원 이하) — 제외
- **중복대출 심사** (기금대출·전세자금(이주비)·주담대 보유 시 불가) — 제외
- **소득추정 경로** (국민연금·건강보험료 납부액 기준) — 제외.
  이 경로는 LTV가 60%로 제한되고 자격판정(100%)과 산정(95%)의 소득 기준이 달라
  단일 LTV 가정과 충돌한다. 원문은 `src/data/incomeRules.js`에 보존(`지원여부: false`).
- **대환대출 경로** (신생아 특례의 1주택자) — 미구현
- **수도권 외 읍·면 면적 완화** (100㎡ / 70㎡) — 미구현
- **LH 신혼희망타운 분양계약자 경로** — 미구현

## 1. 5종 — 자격과 상한 ✅

전 종목 **전용면적 85㎡ 이하** (단 일반가구의 만30세 이상 단독세대주(미혼)만 60㎡).

### 1-1. 일반가구 `general`
**자격** · 민법상 성년 + 부양가족 있는 세대주 또는 세대주로 인정되는 자
(**만 30세 이상은 단독세대주 가능**)

| 티어 | 소득 | 가격 | 한도 |
|---|---|---|---|
| 신혼 | 8,500만 | 6억 | 3.2억 |
| 미성년 2자녀 이상 | 7,000만 | 6억 | 3.2억 |
| 생애최초 | 7,000만 | 5억 | 2.4억 |
| 만30세+ 단독세대주(미혼) · 생애최초 | 6,000만 | 3억 | 2억 |
| 만30세+ 단독세대주(미혼) | 6,000만 | 3억 | 1.5억 |
| 기본 | 6,000만 | 5억 | **2억** |

면적: 기본 85㎡ / 만30세+ 단독세대주(미혼) 60㎡

### 1-2. 생애최초 신혼가구 `firstNewlywed`
**자격** · 생애최초 주택구입 무주택 세대주 **AND** 아래 중 하나
- 신혼부부 (혼인기간 **7년 이내**)
- 결혼예정자 (자산심사 신청일로부터 **3개월 이내**)

소득 **8,500만** / 가격 **6억** / 면적 **85㎡** / 한도 **3.2억**

### 1-3. 신생아 특례 `newborn`
**자격** · 대출접수일 기준 **2년 내 출산**(만 2세 미만 입양 포함)한 가구의 세대주
— 단 **2023.1.1 이후 출생아부터** 적용

소득 **1억 3,000만** / 맞벌이 **2억** (부부 중 **1인 소득 1.3억 초과 시 불가**)
가격 **9억** / 면적 **85㎡** / 한도 **4억**

### 1-4. 청년 주택드림 `youthDream`
**자격** · 청년 주택드림 통장(입주자모집공고일 이전 보유)으로 **청약 당첨**(당첨 시 만 39세 이하)되어
통장과 연계하여 신청. 추가로:
- 통장 가입일(전환일)로부터 대출접수일까지 **1년 이상 가입**
- 대출접수일 기준 **1,000만원 이상 납입** (월 납입실적은 최대 100만원까지 인정)

소득 미혼 **7,000만** / 신혼 **1억** · 가격 **6억** / 면적 **85㎡** / 한도 미혼 **3억** · 신혼 **4억**

### 1-5. 전세사기피해자 전용 `jeonseVictim`
**자격** · 전세사기피해자법 제2조 3호 또는 4호 다목 해당자
소득 **7,000만** / 가격 **5억**(주거용 오피스텔 포함) / 면적 **85㎡** / 한도 **4억**

MVP에서는 비활성(`enabled: false`).

## 3. 상환능력 = DTI ✅ 산식

```
DTI(%) = ( ① 주담대 연간 원리금상환액 + ② 기타부채 연간 이자상환 추정액 ) / 연소득 × 100

① = 본건 디딤돌 원리금(원리금균등)
    + 동일 금융기관 실행예정 기금주담대 + 기존 기금주담대 − 상환예정 주담대
    ※ 체증식 선택 시 초기 10년(대출기간 10년이면 초기 5년) 원리금의 연평균(거치기간 제외)
② = 기타부채 잔액 × 추정금리   ← 원금 상환 스케줄을 보지 않는다. '이자만'
    기타부채 = 주담대 제외 대출(현금서비스 포함) − 상환예정 전세자금대출 − 예적금담보대출
```

- **부부합산 소득·부채 기준**이 원칙.
- **추정금리 = 한국은행고시 예금은행 가중평균 가계대출금리(잔액기준) + 1%p** → 현재 **5.34%**.
  대출신청일 또는 대출승인일 기준. **매달 바뀌는 갱신 대상** → `_policy.md`.
- **DTI 상한 · 산정만기** → `_policy.md` (정부 방침이므로 여기서 관리하지 않음)

**MVP 단순화(의도적)**
- ①은 본건 원리금만 계산. 나머지 세 항은 인자로 열려 있고 기본값 0(기금주담대 중복 보유는 드묾).
  체증식 미구현.
- ②는 항목 구분 없이 '기타 대출 잔액' 하나로 근사(전세·예적금담보 차감은 상담역 영역).
- **금리는 판정에 쓰지 않는다.** 실제 디딤돌 금리는 소득·만기·우대로 사람마다 달라 무시한다.
  다만 ①의 원리금 계산에는 값이 하나 필요하므로 `DIDIMDOL_LOAN_RATE`를 **계산 전용 상수**로만 둔다
  — 화면에 금리로 표시하거나 우대를 판정하지 않는다.

⚠️ **금리 두 개를 합치지 말 것.** ①은 본건 계산용, ②는 시중 부채 추정금리 — 목적이 다르다.

## 4. 소득 인정기준 (요약)

한도에 들어가는 건 입력한 액면값이 아니라 **인정소득**이다. 규정 원문은 `src/data/incomeRules.js`
(Sheet1 FAQ 25문항 + Sheet2 일반규정 전문, 원문 대조 완료).
화면은 `INCOME_TYPES`(15종, 원문 보존)가 아니라 **`ACTIVE_INCOME_TYPES`(13종)**를 쓴다
— 소득추정 2종이 `지원여부: false`로 빠진다.

**판정 대상은 부부합산 최근 1개년 소득.** 근로소득·사업자등록 있는 사업소득·공적연금은 필수 합산.

- **20% 룰** — 2개년 소득차가 20% 이하면 최근년도, 초과면 2개년 평균.
  단 증감이 상시소득이면 20% 초과여도 최근년도.
  (상시소득 판단: 근로소득은 1년 이상 근로계약이 입증되면 상시소득으로 간주,
   근로계약기간 1년 미만은 제외. 사업소득 등은 1년 이상 지속 입증 시 인정.)
- **1년 이하 소득만 있으면 산정 후 10% 차감** (상시소득이면 차감 없음)
- **근로소득은 12개월 미만이면 연환산. 사업소득은 연환산 불가.**
  단 1년 이상 재직자는 최근 일부 개월수를 연환산할 수 없다.
- **온전한 1개월 소득이 아니면 일환산** (재직 1개월 이상 전제. 1개월 미만이면 취급 불가)
- **휴직자는 휴직 직전 소득으로 산정.** 최근 3년 내 1개월 이상 소득이 없으면 무소득 간주.
  복직자는 복직 후 3개월 급여가 없으면 휴직자와 동일하게 본다.
- **비과세소득** — 최근년도 근로소득원천징수영수증상 비과세소득은 제외.
  그 외 서류(소득금액증명원·임금대장 등)의 상여금·비과세소득은 모두 합산.
- **해외 발생 소득 인정 불가.** 신고소득(신용카드 사용액·최저생계비 등)도 인정 불가.
- **무소득 인정은 3가지뿐** — 직장 피부양자 / 지역가입자+전년도 무소득(신고사실없음 사실증명원) /
  전년도 소득금액증명원+퇴직·폐업증명서
- **소득 종류가 2건 이상이면 합산 가능** (중복 산정 주의). 프리랜서는 사업소득으로 분류하되
  재직확인만 경력증명서·위촉증명서 등으로 한다.

⚠️ 현재 엔진은 이 산정 과정을 **한도 숫자에 반영하지 않는다.** 소득 신뢰도(초록/노랑) 논조만 만든다.
반영하려면 인정률 가정이 하나 더 필요해서 **보류 중.**
