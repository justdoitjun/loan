# 은행 일반 주택담보대출 판단기준

> 코드: `src/products/bank.js`(진입 조건·상한 없음) · `data.PRODUCTS.bank`(금융 파라미터) ·
> `src/eligibility/bank.jsx`(화면). 공통(Min 구조 · LTV 표 · 지역별 cap · 잣대 두 개)은 `_common.md`,
> 정부 정책값(지역 가정 · 방공제액)은 `_policy.md`. 코드와 어긋나면 **이 문서를 먼저 고치고 코드를 맞춘다.**
>
> ✅ 원문 확인 / ⚠️ 가정치(현직 판단 대기)

---

## 0. 판정 순서

```
① 진입 조건 — 주택 보유 상태 (LTV 표의 어느 행인가)
② 상한 검사 — 없음 (소득 · 가격 · 면적 상한이 없다)
③ 한도 = Min( LTV기반, DSR기반, 지역별 cap )
```
정부상품과 다른 점: **자격은 거의 없고 담보·상환능력이 전부다.**
상품별 cap이 없다(`cap: null`) → `_common.md`의 **지역별 cap**이 그 자리를 대신한다(`regionCapped: true`).

## 1. 진입 조건 — 주택 보유 상태와 LTV 행 ✅ (`_common.md` LTV 표)

지역 = **규제지역**(`REGION = "regulated"`, 서울 전역 → `_policy.md`).
비율은 `data.LTV_TABLE[REGION]`이고, 행은 `engine.regulatoryLtv`가 고른다. 여러 행이면 **높은 비율**.

| 차주 | 플래그 | LTV | 처리 |
|---|---|---|---|
| 무주택 · 생애최초 | `noHome` · `firstTime` | **70%** | 열림 |
| 무주택 · 서민·실수요 | `noHome` · `householdHead` · 소득 ≤ 9천만 · 가격 ≤ 8억 | **60%** | 열림. 세대주는 가족정보가 있을 때만 |
| 무주택 · 일반차주 | `noHome` (위 우대 없음) | **40%** | 열림 |
| 1주택 · 처분조건부 | `disposing` | **40%** | 열림 — 일반차주. 처분 약정 이행은 상담역 확인. 서민·생애최초 아님 |
| 1주택 · 유지 | `oneHome` and not `disposing` | **0%** | 닫힘 — "처분조건부로 바꾸면 열려요" |
| 2주택 이상 | `multiHome` | **0%** | 닫힘 |

- 서민·실수요 요건은 `_common.md` (`REAL_DEMAND`). 셋이 모두 맞을 때만 60%.
- 가족정보(생년월일·배우자·자녀)가 없으면 세대주를 추정할 수 없다. 그때는 60%를 주지 않고, 카드에 그 길을 적는다.
- 소득 가정으로 부부합산이 9천만원을 넘으면 서민 행이 닫힌다. 천장 계산은 9천만원 지점과 소득 최댓값을 둘 다 보고 한도가 더 큰 쪽을 쓴다.
- 지방 · 규제지역 외 수도권 열은 표에만 있다. `REGION`이 바뀌면 `regulatoryLtv`가 그 열을 읽는다.

**질문** — ① 주택 보유 상태 ② 무주택이면 생애최초 ③ 배우자 소득(DSR 합산용).
생애최초는 LTV를 40%에서 70%로 올리므로 은행 경로에서 묻는다. 정부탭에서 이미 답했으면 다시 묻지 않는다.
세대주·결혼·청년통장은 은행탭에서 묻지 않는다.
답은 정부탭과 같은 `elig` 한 벌에 들어간다(`homeCount` · `disposeExisting` · `firstTime` · `bankIncomeJoint` · `spouseBand`).
③은 `bankIncomeJoint`(합산 / 본인 소득만)이다. 가족정보의 배우자 유무(`hasSpouse`)와 다른 질문이라 서로를 지우지 않는다.
은행탭에서 안 골랐으면 정부탭을 끝까지 답했을 때만 그 답을 빌린다(배우자 있음 = 합산, `person.bankJointOf`).
진입 조건에는 **민법상 성년**도 있다(`adult`). 은행탭은 생년월일을 묻지 않으므로, 정부탭에서 미성년으로 확인된 경우만 닫힌다.

## 2. LTV와 방공제

| 항목 | 값 | 코드 |
|---|---|---|
| LTV | 1절 표. 폴백(행을 못 고를 때)은 일반차주 40% | `engine.regulatoryLtv` · `PRODUCTS.bank.LTV` |
| 방공제 | **MCI로 상쇄할 수 있다** | `offsetsRoomDeduction: true` = 보전을 켤 수 있음. 방법 화면 기본은 아니오(차감). 네일 때만 상쇄 |

⚠️ MCI 가입 가능 여부는 방법 화면에서 네를 누르면 팝업으로 안내한다. 창구에서 확정되기 전에는 한도에서 뺀다.

## 3. 상환능력 = DSR ⚠️ (차주단위 40%)

```
DSR(%) = ( 본건 연간 원리금 + 기존 부채 연간 원리금 ) / 연소득 × 100  ≤ 40%
```

| 항목 | 값 | 코드 | 비고 |
|---|---|---|---|
| DSR 상한 | 40% | `PRODUCTS.bank.ratio` (= `RULE.DSR`) | 은행 차주단위 |
| 본건 산정만기 | 30년 | `PRODUCTS.bank.years` | ⚠️ 실제 만기(최장 40년)를 안 묻고 30년으로 고정 |
| 본건 실제 금리 | 4.0% | `calcRate` (= `RULE.loanRate`) | ⚠️ 가정치. **계산 전용** — 화면 금리(`rateLabel`)와 별개 |
| 스트레스 금리 | **3%p** | `PRODUCTS.bank.stressRate` | 신규 취급시점 가산. 실제 금리와 다른 숫자. 화면 금리에는 더하지 않는다 |
| 기존 부채 환산 | 종류별. 아래 표 | `engine_bank_dsr.bankExistingAnnual` · `DEBT_KINDS[].dsr` | 원금 나누기는 확정. 실제 금리는 아직 잔액만 있어 TODO |
| 부채를 보는 법 | **원리금 전체** | `DEBT_VIEW.bank = "principalAndInterest"` | 디딤돌(이자만)과 다른 점. 디딤돌은 이 표를 읽지 않는다 |

- **소득**: 차주단위가 원칙. 배우자 소득을 합산하면 **배우자 부채도 합산**된다 →
  화면은 "배우자 소득을 넣었으면 부채 슬라이더에도 배우자 대출을 같이 넣으세요"로 안내한다.
  결혼예정자(예비배우자)는 합산 대상이 아니다 — 정부탭에서 `planned`로 답해도 은행 DSR 소득에 넣지 않는다.
  코드: `PRODUCTS.bank.incomeBasis = "borrower"` → `ctx.borrowerIncome`. 서민·실수요의 9천만원 요건만 부부합산으로 본다.
- **기존 부채 입력**은 종류별로 받는다(`data.DEBT_KINDS`). 월상환액·만기는 안 묻는다.
  종류를 늘리거나 줄이는 건 그 목록만 고친다. 방법 화면에서는 확정한 종류마다 얼마를 줄일지 따로 움직인다.
- **기존 부채는 종류마다 1년 상환액으로 바꾼 뒤 더한다.** 파라미터는 `DEBT_KINDS[].dsr`, 계산은 `src/engine_bank_dsr.js`. `engine.limitParts`의 은행 경로만 그 함수를 부른다. 디딤돌 DTI는 주택담보를 뺀 합계 × 이자(`combinedDebtBalance(debt, true)`).
- 월상환액·만기는 묻지 않는다.
- **스트레스 금리는 실제 금리와 별개다.** 연간 이자상환액은 실제 대출금리에 신규 취급시점의 스트레스 금리를 더해 산정한다. 화면 금리에는 더하지 않는다. 본건 원리금균등도 그 합산 금리(4.0% + 3%p)로 환산한다. 금리로 이자를 만드는 기존 부채(신용·마이너스통장·전세·비주택 담보)도 같다. 실제 금리를 받기 전에는 `RULE.creditRate`(5.5%)로 자리를 채운다. 원금만 나누는 카드·자동차와, 실제 1년 원리금을 쓰는 주담대에는 이 가산을 붙이지 않는다.
- 종류별 연 상환액 (`engine_bank_dsr.js`):

  | 종류 | 연 상환액 |
  |---|---|
  | 주택담보 | **실제** 1년 원리금. 잔액을 만기로 나누지 않는다 |
  | 전세자금 | 원금 제외. **이자만** (실제 금리 + 스트레스 금리) |
  | 신용 | 잔액 ÷ **5년** + 이자 (실제 금리 + 스트레스 금리) |
  | 마이너스통장 | 신용과 같다. 한도 ÷ **5년** + 이자 (실제 금리 + 스트레스 금리) |
  | 비주택 담보 | 잔액 ÷ **8년** + 이자 (실제 금리 + 스트레스 금리) |
  | 카드 | 잔액 ÷ 약정만기, 최장 3년. **지금은 3년** |
  | 자동차 | 원금 ÷ **3년** |

- 화면은 아직 잔액만 받는다. 그래서 실제 대출금리와 주담대의 실제 1년 원리금은 코드에 `//TODO`다. 실제 금리를 받기 전에는 잔액 × (5.5% + 스트레스 3%p)로 이자 자리를 채운다. 주담대 잔액은 1년 원리금이 아니므로, 그 숫자를 받기 전에는 은행 DSR에 **넣지 않는다**.
- 신용 1,000만 원을 줄이면 원금 200만 + 이자 85만(5.5% + 3%p), 합계 연 285만이 열린다. 마이너스통장 한도 1,000만도 신용과 같이 연 285만이다. 전세 1,000만은 이자 85만만 열린다. 카드 1,000만은 원금 약 333만(3년)만 열린다. 자동차 1,000만도 원금 약 333만(3년)이다. 비주택 담보 1,000만은 원금 125만 + 이자 85만이다. 디딤돌은 이 표와 무관하게 합계에 이자만 곱한다.

## 4. 지역별 cap ✅ (`_common.md` 표)

코드: `data.REGION_CAP`(표 그대로) + `engine.regionCapOf(price)`. 은행만 `regionCapped: true`.
정부상품은 제한 없음(플래그 없음 → `parts`에서 빠진다).
`_policy.md`의 옛 `RULE.seoulCap`은 이 표로 대체됐다 — 예산 화면 천장(`engine.evaluate`)도 같은 함수를 쓴다.

## 6. 검증 대기 목록

| 항목 | 상태 |
|---|---|
| DSR 산정만기 30년 고정 vs 실제 만기 입력 | ⚠️ 질문을 안 늘리려고 고정. 40년 만기면 한도가 약 15% 더 나온다 — 현직 판단 |
| 스트레스 금리 3%p | ✅ 서울(규제지역) 신규 취급 가산. 산식: 연간 이자 = (실제 금리 + 3%p) × 잔액. 화면 금리와 별개 |
| 실제 대출금리 · 주담대 실제 1년 원리금 | ⚠️ 화면은 잔액만 받는다. 실제 금리는 임시 5.5%이고 이자는 거기에 스트레스 금리를 가산. 주담대 원리금은 받기 전 0. `engine_bank_dsr.js` TODO |
| 카드 약정만기 | ⚠️ 최장 3년. 만기를 안 물어 3년 고정 |
| MCI 상쇄 | ⚠️ 방법 화면 기본은 차감. 네를 고르면 상쇄로 계산하고, 가입 가능 여부는 팝업으로 안내 |
| 처분조건부 1주택 = 일반차주 40% | ✅ 규제지역 표 / ⚠️ 처분 기한(6개월) 안내는 상담역 |
| 생애최초 70% · 서민·실수요 60% · 일반 40% | ✅ 규제지역 (`regulatoryLtv`). 생애최초 전입 기한은 상담역 |
| 지방 · 규제지역 외 수도권 LTV 열 | 표에만 있음. 서울은 `regulated`라 그 열을 타지 않는다 |

## 7. 코드 매핑

| 규정 | 코드 |
|---|---|
| 진입 조건(성년 · 주택 보유 상태) | `src/products/bank.js` `requires: ["adult"], [["noHome","disposing"]]` · 플래그는 `engine.deriveFacts` |
| LTV 행 | `data.LTV_TABLE` · `data.REAL_DEMAND` · `engine.regulatoryLtv`. 한도는 `limitParts`가 그 비율을 받는다 |
| 상한 없음 | `incomeCap`·`priceCap`·`loanCap` 값 `null` → `engine.judgeRule`이 검사에서 뺀다 |
| Min(LTV, DSR, 지역별 cap) | `engine.limitParts` — `cap: null`이면 상품 cap 항이 빠지고 `regionCapped`면 지역 cap 항이 붙는다 |
| 기존 부채 연 상환액 | `src/engine_bank_dsr.js` `bankExistingAnnual`. 은행 경로에서만 호출 |
| 화면 | `src/eligibility/bank.jsx` — 주택 보유 → 무주택이면 생애최초 → 배우자 소득 → 카드(한도 / LTV 행 / 금리 / 실행시점) |
| 진행 상태 | `person.bankSteps` — 지도 정밀 모드는 정부 **또는** 은행 답변이 차면 켜진다(`personReady`) |
