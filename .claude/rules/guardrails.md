# 가드레일 (항상 지킬 것 — 절대 어기지 말 것)

1. **애매하면 노랑 = "상담역이 확정."** 정밀 대출 가부는 항상 상담사에게 넘긴다.
2. **거절로 문을 닫지 말 것.** 회색/닫힘에도 "이렇게 하면 열려요" 경로를 준다.

## 숫자를 다룰 때 (위 1·3의 실무 규칙)

- **검증 안 된 숫자를 확정처럼 쓰지 않는다.** 상품 규칙 문서의 표기 규약을 그대로 따른다:
  **✅ 원문 확인 / ⚠️ 가정치 / ❓ 코드·원문 불일치.**
- ⚠️ 상태의 숫자에 화면 문구를 의존시키지 않는다(예: "6천만원까지 됩니다" 확언).
- 규제값을 바꿀 땐 **규칙 문서를 먼저 고치고 코드를 맞춘다.** 코드에만 넣으면 출처가 사라진다.
- 주기적 갱신이 필요한 값(`ESTIMATED_DEBT_RATE` 등)은 갱신 대상임을 문서에 남긴다.
